# Changelog

## 1.0 (November 2026)
- Product types with barcode prefixes and custom fields.
- Barcode scanning, automatic barcodes, purchases and sales with stock protection.
- Dashboard, low-stock list and transaction log.
- DYMO LabelWriter 550 label printing.
- One server for the whole office network, Windows start and firewall scripts.
- Security fix: barcodes are now escaped on the Scan page and in the label window.
